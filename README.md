# Blackjack in Python

A simple Blackjack game built in Python while I was learning the fundamentals.

## Features

- Deals cards to both the player and dealer
- Lets the player choose to hit or stand
- Dealer automatically draws until reaching 17
- Handles Aces as either 11 or 1
- Detects blackjack, busts, wins, losses and draws

## Concepts Used

- Functions
- Lists
- `if` / `elif` / `else`
- `while` loops
- User input
- Randomisation
- Basic game logic
